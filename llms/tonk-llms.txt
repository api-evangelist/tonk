# Tonk

> Tonk (by Tonk Labs) is a containerized format, host environment, and protocol for
> multiplayer, local-first software you keep and share like files. A .tonk bundle packages
> both an application and its data into a single self-contained file that runs anywhere,
> works offline, and stays under user control. Under the hood it uses a document-based
> virtual file system built on Automerge CRDTs, a browser/WebAssembly runtime compiled from
> Rust, and peer-to-peer synchronization via WebSocket relays. Tonk is open source (MIT).
> It is not a hosted REST API — it is a toolkit, runtime, and set of client libraries.

## Notes
- No hosted REST API, OpenAPI specification, or OAuth server is published.
- Core is Rust compiled to WebAssembly; apps run in a browser-based host runtime.
- Authentication for hosted Tonk apps is handled via @tonk/tonk-auth (Clerk).
